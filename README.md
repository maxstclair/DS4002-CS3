# DS4002-CS3

This repository contains the necessary information to complete the Case Study: data, scripts, reference materials, and a description of the deliverable. 

## Data
The necessary data is included in the DATA folder. It contains both the original, uncleaned datasets and various stages of data manipulation. As denoted in the scripts, impute_df is used as the final cleaned dataset.

## Scripts
The necessary scri[ts to clean the data and run the analysis are located in the SCRIPTS folder. The numbers in the filenames indicate the order that the scripts can be run if starting from original uncleaned data. You can also start with the analysis scripts and use the appropriate cleaned datasets from the DATA folder.

## Reference Materials
The reference materials contain background information about the project, specifically describing the problems faced by our current energy grid and the function of power markets.
